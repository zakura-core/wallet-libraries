# zakura-transparent-txid-client

A synchronous, transport-agnostic wallet client for the tiered txid display PIR publication. It depends only on `zakura-transparent-{events,native,shard}`; the wallet supplies the transport. The library target keeps the name `transparent_txid_client`, so code moved from
wallet-pir's `transparent-txid-client` 0.1.0-rc.4 keeps its paths.
