# zakura-transparent-native

Transparent's native PIR profiles over `zakura-pir-native`: the per-table
profile choice, seed derivation, published scheme descriptions and the
batched hint used by the transparent shard server and the wallet. The library
target keeps the name `transparent_native`.

`testdata/batched_hint_kat.json` is generated by the independent Python
oracle `testdata/batched_hint_kat.py`; the Rust test `known_answer_vectors`
checks the batched hint against it.
