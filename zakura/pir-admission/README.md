# pir-admission

Bounded HTTP uploads, per-client caps and cancellation-safe evaluation admission.

This package is maintained and released by wallet-libraries. Node ingestion, production configuration, process identity and monitoring belong to wallet-pir.

The implementation and existing fixtures were extracted from wallet-pir; serialized formats and serving behavior are preserved. See [receiver library ownership](../../docs/receiver-library-ownership.md) for the release and validation boundary.
